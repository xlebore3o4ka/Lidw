# Issues

Open questions, deferred work, and observations about the **compiler
project** (not the language spec — that's `docs/`). Each issue is a
short file with a status, the problem, and what would fix it.

Naming: `NNN-short-slug.md`. Numbers are a monotonic counter, never
reused. Statuses: `open`, `deferred`, `resolved` (kept for the
record), `wontfix`.

When something isn't worth fixing right now but shouldn't be
forgotten, drop a file here and mention it in the commit message.
